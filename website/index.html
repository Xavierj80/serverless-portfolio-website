Project 1

Bastion Forge: Immutable Compliance Vault (Founder Project)

Problem: Small healthcare, legal, and financial firms must keep records for set retention periods under HIPAA and SEC Rule 17a-4. Enterprise immutable-storage tools are priced and built for large companies, leaving smaller firms without an affordable option.

What I Built: A veteran-owned “Immutability as a Service” platform. Client files go into S3 Object Lock vaults that even the administrator can’t delete before retention expires. It has Cognito login with MFA, industry-specific client portals, and continuous monitoring with GuardDuty, Security Hub, Config, and CloudTrail. All of it is deployed with Terraform.

Hardest Challenge: An authentication Lambda failed for months, and the root cause turned out to be a wrong CloudWatch log path in its IAM policy. Through this problem, I learned to read IAM policies line by line.

What I'd Do Differently: Start with a multi-account AWS Organizations design (separate app, vault, and security accounts) to limit the blast radius of a compromised account.

Technologies: S3 Object Lock, KMS, Cognito, Lambda, CloudWatch, API Gateway, DynamoDB, Amplify, WAF, GuardDuty, Security Hub, AWS Config, CloudTrail, SNS, Route 53, Terraform, Python, JavaScript

Project 4

Secure AI-Powered Sentiment Analyzer

Description: I developed a Secure AI-Powered Sentiment Analyzer, a serverless API on AWS designed for secure text analysis. Using Python, Lambda, API Gateway, Comprehend, and Terraform, I built a system that analyzes text sentiment within a private network, leveraging VPC Endpoints for security. A key challenge was configuring secure access to Comprehend without public internet exposure. This project gave me valuable experience in serverless architecture, API security, and AWS networking.

Goal: The goal of this project is to create a robust, scalable, and secure serverless API that can analyze the sentiment of text data while prioritizing the privacy and security of that data.

Technologies: AWS Lambda, Amazon Comprehend, VPC Endpoints, API Gateway, Amazon Virtual Private Cloud, Terraform, and Python.
